# Shizuo 2.24.4

This release removes several small but persistent friction points in everyday board management.

## Highlights

- The Inbox now has a clear action from both its home card and board menu. The Inbox remains as the safe default capture destination; clearing it removes its content rather than its identity.
- Any ordinary board can be deleted independently, including boards whose cards originated in the Inbox.
- Workflow templates have one clear entry point: open the template manager, then save the current board or create from an existing template.
- Collaboration and version-history dialogs have cleaner spacing and a single intentional scroll region.

## Upgrade

Reload the unpacked extension from `chrome://extensions`. Existing local boards and templates stay unchanged.
