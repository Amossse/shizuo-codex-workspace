# 能力说明

## 核心能力

- 网页、选区、图片、链接和本地文件收集
- 可连接、分组、搜索和版本回溯的本地白板
- 带素材上下文的本地 Codex 任务，支持进度、停止、重试和多轮追问
- 网页内问答、翻译、总结、分析和粘贴图片提问
- 本地导出、导入和完整备份

## 结果复用

任务结果可以作为文字、图片或知识卡保留在画布上，并记录来源。白板可以保存为可复用的工作流模板。

## 高级与实验能力

以下能力不在首次使用路径中，适合完成基本连接后按需开启：

- 动态工作流与定时执行
- 可信内网协作与外部 Codex 接入
- 本地终端、Codex 会话预览和 AGY Runtime
- HyperFrames / Remotion 视频，以及 Kokoro 后置旁白和字幕

这些能力都保持本地优先，并在执行前要求相应的权限或依赖。
