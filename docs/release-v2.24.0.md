# Shizuo 2.24.0

Shizuo is a local-first visual workspace for Codex: capture context from the browser or local files, organize it on an infinite canvas, and let local agents act with visible results.

## Highlights

- A clearer first-run path from capture to canvas to Codex
- Automatic local bridge reconnection and observable task status
- Context-aware page chat with pasted-image support
- Dynamic and scheduled workflows with pending/running/result containers
- Reusable knowledge cards, provenance, board history, and cross-board search
- Optional HyperFrames or Remotion video with Kokoro post-production
- Trusted-LAN collaboration and Codex/AGY runtime switching for advanced setups

## Install

1. Download `shizuo-2.24.0.zip` from this release and unzip it.
2. Open `chrome://extensions`, enable Developer mode, and choose Load unpacked.
3. Select the unzipped folder.
4. Optional: connect local Codex by following the README quick start.
